# Test Video

This directory contains recorded test footage for the
`GPS-and-Lidar-Fusion-lidar-navigation` project.

## Included recording

| File | Description |
|---|---|
| [`test1.mp4`](test1.mp4) | Rover test recording used to demonstrate and review the navigation system. |

`test1.mp4` is approximately 3 minutes 47 seconds long. It is a 3840 × 2160
(4K) HEVC/H.265 video with AAC audio and is approximately 727 MB.

## Playback

On Ubuntu, open the file from the desktop or play it with VLC:

```bash
vlc "test videos/test1.mp4"
```

Because the directory name contains a space, quote the path in shell commands.
The HEVC codec may require a compatible media player or codec package.

## Repository note

The recording is a large binary file. Avoid making unnecessary copies or
re-encoding it in place. If more recordings are added, use descriptive names
and document what each test demonstrates in this file.
